# Glance backend

Node.js + TypeScript backend for **Glance — Telegram Digest & Drafts on G2**
(Even Realities, Track 01). Polls the Telegram test channel, builds a digest
with a local-LLM summary + reply draft, and relays replies through the bot.

## Endpoints

| Method | Path | Description |
|---|---|---|
| `GET` | `/` | API index |
| `GET` | `/health` | Liveness + last poll status |
| `GET` | `/digest` | Digest items (one per chat): title, summary, draft, unread |
| `GET` | `/digest/:id` | Detail: last 20 messages + summary + AI draft |
| `POST` | `/reply` | `{itemId, text}` → `sendMessage` via the bot |
| `POST` | `/stt` | Speech-to-text (day 4): raw PCM 16 kHz/16-bit/mono, or JSON `{audio: base64}` (WAV/any ffmpeg-decodable); cap 1 MB. Returns `{ok, model, text, language, duration_s}` |

## Run

```bash
npm install
npm run build
npm start          # listens on http://127.0.0.1:3000
```

Env: `PORT` (default 3000), `POLL_MS` (default 15000),
`OLLAMA_HOST` (default `http://127.0.0.1:11434`),
`OLLAMA_MODEL` (default `qwen2.5:3b`), `DATA_DIR` (default `backend/data`).

## How Telegram is reached (no token in this repo)

The bot token is **never** stored here — not in code, env files, logs, or
commits. Bot API calls (`getUpdates`, `sendMessage`) are delegated to the
registered connector helper
`~/workspace/custom-connectors/custom.telegram-bot/bin/telegram-bot.py`,
which holds the credential in Muse's secure store and swaps it into the
request path. This backend only spawns that helper and parses its JSON.

## Summaries

`GET /digest` summaries and reply drafts are generated by local Ollama
(`qwen2.5:3b`); when Ollama is unavailable or slow, the backend falls back
to an extractive summary (first messages, truncated) so the endpoints keep
working. No paid API, no API key. Day-4 tuning (`summarize.ts`): generation
timeout 120 s → 600 s, `num_predict` 300 → 180 — on this shared 1.5-CPU VM
a qwen2.5:3b generation runs at <1 tok/s under parallel load, so the old
120 s timeout fired on every summary and the digest silently lost its draft
(which disables the glasses write path). The JSON answer is ~50–90 tokens,
so 180 is plenty.

## STT (day 4)

`POST /stt` transcribes glasses-mic audio locally with faster-whisper
(model `tiny`, no paid API). Setup is a Python venv (system `pip --user` is
blocked by PEP 668 on this VM):

```bash
python3 -m venv ~/workspace/dorahacks/even-realities/stt-venv
~/workspace/dorahacks/even-realities/stt-venv/bin/pip install faster-whisper
```

`src/stt.ts` keeps a persistent daemon (`stt-daemon.py`, model loaded once)
and falls back to a one-shot worker (`stt.py`) if the daemon is down.
Measured 27 Nov 2026 (JFK 11 s speech): daemon cold start ~19 s, warm
~3.4 s; one-shot ~21–24 s per request; silence → empty text. `av` is pinned
to `==15.1.0`: faster-whisper 1.2.1 breaks with `av` 19 (`av.open` rejects
the `metadata_errors` kwarg). `/health` reports `stt: {model, ready}`.
